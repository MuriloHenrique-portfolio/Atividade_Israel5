# MineHub

Projeto desenvolvido em HTML com o tema Minecraft.

O site possui * abas principais, com páginas sobre Notícias, Mobs, Itens, Dimensões e Sobrevivência. Também possui tela de cadastro e login, além de imagens, áudios, vídeos, formulários e outras funções trabalhadas durante as aulas.

O projeto foi feito utilizando HTML, sem CSS e JavaScript.
