Gambiarras do MineHub

Durante o desenvolvimento do MineHub, algumas ferramentas do HTML foram utilizadas de maneiras diferentes de sua finalidade principal. Nesta página estão dois exemplos utilizados no projeto.

Table — Organização do layout

A tag <table> é utilizada normalmente para apresentar informações organizadas em linhas e colunas.

No MineHub, ela foi utilizada como uma forma de organizar visualmente alguns elementos da página, principalmente o cabeçalho e o menu de navegação.

Vídeo sobre Table

Exemplo utilizado no MineHub

<table width="100%" border="1" cellpadding="10">

    <td>

        Conteúdo do site

    </td>

</table>

Align — Alinhamento dos elementos

O atributo align foi utilizado no MineHub para definir o alinhamento de alguns elementos dentro da página.

Por exemplo, quando utilizamos align="center", o conteúdo é colocado no centro da área disponível.

No projeto, ele foi utilizado principalmente para centralizar títulos, textos, imagens e alguns elementos do conteúdo.

Quando o align não é utilizado, o conteúdo normalmente segue o alinhamento padrão do elemento, que geralmente começa pelo lado esquerdo da página.

Assim como o uso de table para organizar o layout, o atributo align é uma forma antiga de controlar a apresentação da página. Atualmente, esse tipo de alinhamento é feito utilizando CSS.

Exemplo utilizado no MineHub

<h1 align="center">

        Bem-vindo ao MineHub

    </h1>


    <p align="center">

        Este texto aparece centralizado.

    </p>

Meta Refresh — A tela de carregamento

O elemento <meta http-equiv="refresh"> foi utilizado no MineHub para criar as telas de carregamento das dimensões.

Ele faz o navegador atualizar ou acessar outra página depois de um determinado período de tempo.

No projeto, utilizamos essa função para mostrar uma tela de carregamento durante alguns segundos antes de abrir a página da dimensão escolhida.

Exemplo utilizado no MineHub

<meta http-equiv="refresh"
content="10;url=biomas_nether.html">

Nesse exemplo, o número 10 representa o tempo de espera em segundos. Depois desse período, o navegador acessa a página indicada em url.

Essa foi uma solução simples para criar uma transição de carregamento sem utilizar JavaScript.

Por que usamos essas técnicas?

O MineHub foi desenvolvido somente com HTML, sem CSS e sem JavaScript. Por isso, algumas soluções alternativas foram utilizadas para conseguir determinados efeitos durante o desenvolvimento.

Essas técnicas funcionam no projeto, mas existem formas mais adequadas de realizar essas funções em um site desenvolvido com tecnologias atuais.
